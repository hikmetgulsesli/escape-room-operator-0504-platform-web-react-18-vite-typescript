# Escape Room Operator Platform PRD ## Overview A high-performance management dashboard for escape room operators, built with React 18, Vite, and TypeScript. Focuses on real-time game tracking, player management, and operational efficiency. ## Core Features - **Live Room Monitoring:** Status cards for all escape rooms. - **Game Control Center:** Active timers, hint delivery, and puzzle checklists. - **Inventory & Key Tracking:** Digital management of physical game assets. - **Event Logging:** Automated and manual logging of all game events. - **Emergency Protocols:** One-click emergency stop and reset functions. - **Data Management:** LocalStorage persistence with export/import capabilities. ## Technical Stack - React 18, Vite, TypeScript - Tailwind CSS (Dark Theme) - Lucide React Icons - LocalStorage for persistence ## Design Direction - **Theme:** Dark Mode (Cyber-command center aesthetic) - **Primary Color:** #2563EB (Action Blue) - **Secondary Color:** #475569 (Slate) - **Warning/Emergency:** #DC2626 (Alert Red) - **Success:** #16A34A (Active Green) - **Typography:** Inter (Clean, high readability)
